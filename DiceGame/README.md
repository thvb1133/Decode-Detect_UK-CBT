# DiceGame

Console dice game for three players (CST2110 Task 1).

Open this folder in NetBeans as a Java project with an Ant build. The source and class format are Java 11 (`javac.source` and `javac.target` in `nbproject/project.properties`). Run the project from the IDE. The main class is `dicegame.DiceGame`.

Before zipping the submission, right-click the project and choose Clean so compiled class files are removed.

An optional program argument fixes the dice for repeat testing, for example `42`. Leave it empty for a normal game.
